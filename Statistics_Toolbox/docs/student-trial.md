# Student trial: does StatLab work without help?

> The on-screen version is `trial.html`: the students record their sessions there, download a JSON file, and you pick all the files on the same page to get a class summary. This sheet is the printed version for sitting next to a student.

Ask 3 to 5 students (a mix of first-years and B.Tech data-science learners) to try it **without you explaining anything**. Sit next to them, say nothing, and write down where they pause. Twenty minutes each is enough.

## Give each student two textbook questions (they pick the tools themselves)

1. A sample of 25 students has a mean score of 72 with a standard deviation of 8. Test at the 5% level whether the population mean is 70. *(summary input, one-sample t)*
2. Of 120 students taught with method A, 45 passed; of 110 taught with method B, 30 passed. Is there a difference in pass rates? *(two-proportion z)*

Then one of their own: a question from the textbook they are using this week.

## What to watch and record

| Question | Notes |
|---|---|
| Found the right tool without help? (how long, which wrong tools first) | |
| Understood "What does your question give you?" (raw vs summary)? | |
| Understood the graph (shaded region, critical value, test statistic)? | |
| Trusted the answer? (did they check it against the textbook's answer) | |
| Used the worked solution, or only the final number? | |
| Anything confusing: a word, a label, a button | |
| Anything missing that they expected | |
| Phone or laptop? Anything hard to tap or read on the phone | |

## Four closing questions

1. What was the hardest part?
2. What would you change first?
3. Would you use this for your own homework or exam revision? Why or why not?
4. Which tool did you wish existed?

Send the filled-in notes (or open an issue on the repository) and they become the next to-do list.
