Which tool should I use?

Start from the question you are asking. Each card names the tools that answer it and says when to prefer one over another. Selecting a tool opens it in StatLab.

Describe one set of numbers

  • What is a typical value?

    Mean Median Mode

    Mean for roughly symmetric data; median when there are outliers or a long tail; mode for the most common value.

  • How spread out is it?

    Standard deviation IQR Range Coefficient of variation

    Standard deviation pairs with the mean, IQR with the median. The coefficient of variation compares spread across different units.

  • What does its shape look like?

    Histogram Boxplot Skewness Kurtosis

    Plot first, then read the numbers. Skewness and kurtosis need at least 3 and 4 values.

  • Where does a value stand in the data?

    Z-scores Percentiles Ranking

    Z-scores assume a roughly bell-shaped distribution; percentiles and ranks do not.

Clean and prepare data

  • Is there an outlier?

    IQR rule Z-score rule Boxplot

    The IQR rule is robust to skewed data; the Z-score rule assumes a roughly normal distribution.

  • Make skewed data more symmetric

    Log transform Box-Cox Winsorization

    Log and Box-Cox need positive values. Winsorization caps extreme values instead of changing the scale.

  • Put variables on one scale

    Min-max normalization Z-scores Binning

    Normalization maps to a fixed range; Z-scores centre on 0 with spread 1.

  • Is my data normal?

    Q-Q plot Shapiro-Wilk Anderson-Darling Kolmogorov-Smirnov

    Look at the Q-Q plot first; tests flag tiny departures in large samples and miss big ones in small samples.

Work with a probability distribution

  • Probability of a value or range

    PDF PMF CDF Survival function

    PDF for continuous variables, PMF for counts, CDF for 'at most', survival for 'more than'.

  • Find the cutoff for a given probability

    Quantile function

    The inverse of the CDF: the value below which a chosen share of the distribution lies.

  • Mean, variance, shape of a named distribution

    Expected value Variance Skewness Kurtosis

    Closed-form results from the parameters you enter.

  • Which distribution fits my data?

    Fit distribution (MLE)

    Maximum-likelihood fit for the distributions the tool offers.

  • Simulate data

    Random number generation

    Give a seed to repeat the same numbers.

Relationships between variables

  • Two numeric variables, straight-line relationship

    Pearson Covariance Simple regression

    Pearson assumes a linear relationship and is sensitive to outliers.

  • Two numeric variables, ranks or outliers

    Spearman Kendall's tau Distance correlation

    Rank-based measures ignore the exact values; distance correlation also detects non-linear links.

  • A numeric and a yes/no variable

    Point-biserial

    Numeric outcome against a two-category variable.

  • Two categorical variables

    Contingency table Chi-square independence Cramér's V Phi (2×2)

    Chi-square tests whether they are related; Cramér's V and phi say how strongly.

  • Control for a third variable

    Partial correlation

    Relationship between X and Y with Z held fixed.

  • Many variables at once

    Correlation matrix VIF

    VIF flags predictors that duplicate each other before you fit a regression.

Compare groups or test a claim

  • One sample against a known value

    One-sample t One-sample z Proportion z Binomial exact

    t when the standard deviation is estimated; z only when it is known; binomial exact for a small number of yes/no trials.

  • Two independent groups, numeric

    Two-sample t Mann-Whitney U

    t assumes roughly normal groups; Mann-Whitney compares ranks and needs no normality.

  • Same subjects measured twice

    Paired t Wilcoxon signed-rank Sign test

    Wilcoxon and the sign test do not need normal differences.

  • Three or more groups, numeric

    ANOVA Kruskal-Wallis Friedman (repeated measures)

    ANOVA assumes similar spreads; Kruskal-Wallis is the rank-based alternative.

  • After a significant ANOVA: which groups differ?

    Tukey HSD Bonferroni Scheffé

    Tukey for all pairs, Bonferroni for a few planned comparisons, Scheffé for flexible contrasts.

  • Do groups have equal variances?

    F-test (two groups) Levene Bartlett

    Levene is less sensitive to non-normal data than Bartlett.

  • Adjust for a covariate, or several outcomes

    ANCOVA MANOVA

    ANCOVA compares group means after adjusting for a covariate; MANOVA tests several outcomes together.

  • Counts against expected counts

    Chi-square goodness of fit

    Needs expected counts of about 5 or more.

  • Paired yes/no or several yes/no conditions

    McNemar Cochran's Q

    McNemar for two conditions, Cochran's Q for three or more.

  • Is the sequence random?

    Runs test

    Looks for streaks above and below the median.

Fit and check a regression model

  • Predict one number from one predictor

    Simple linear regression

    Slope, intercept, R² and the overall F test.

  • Predict from several predictors

    Multiple linear regression

    Check predictors with VIF first.

  • How good is the model?

    Model summary Overall F test

    R², adjusted R², RMSE and residual standard error from actual and predicted values.

  • Are individual coefficients significant?

    Standard errors t statistics

    These need some scatter around the line; a perfect fit has no standard errors.

  • Residual problems

    Durbin-Watson Cook's distance

    Autocorrelation of residuals, and observations that pull the fitted line.

Not sure it fits your data? Each tool lists its assumptions in the worked solution, and the README's accuracy table says where an approximation is used.
